# Ficha de Vistoria - Itazi Engenharia

Versão de campo reconstruída sobre os fontes originais.

## Melhorias desta versão
- Mantém separados todos os campos originalmente urbanos e rurais.
- Número do imóvel separado.
- E-mail disponível na ficha rural e telefones adicionais.
- Outros interessados dentro do bloco cadastral original.
- Latitude/Longitude e UTM exibidos nas duas fichas, conforme solicitado.
- Fotos preservam a imagem-base, GPS original da foto e GPS da ficha.
- Botão **Alterar coordenada** permite Foto, Ficha, Manual ou Sem coordenada.
- Escolher Sem coordenada não apaga o GPS original.
- CSV individual continua legível; CSV do projeto gera fichas, interessados, fotos e benfeitorias em tabelas separadas.
- Painel simples de campo: projeto atual, fichas de hoje e continuar.
- Situação simples: Em andamento ou Concluída.
- Download e compartilhamento com seleção de formatos.
- Cache offline `ficha-14`.

## Publicação
Extraia na raiz do repositório GitHub e publique pelo GitHub Pages. Abra uma vez com internet para renovar o cache offline.

## Compatibilidade de fotos antigas
Fotos adicionadas nesta versão preservam a base sem carimbo e o EXIF original. Fotos de versões anteriores não possuem essa cópia histórica; nelas ainda é possível usar coordenada da ficha ou manual, mas o GPS original só estará disponível se já tiver sido salvo no registro antigo.
